I'm an **M2 student in Data and Economics** at **CY Cergy Paris Université**, in a program fully taught in English. I love applied data analysis, especially when it helps answer real questions about the **environment**, **cities** and **sports events**.

My little toolbox is Python, econometrics and data visualisation: I clean the data, build the model, test the hypothesis and find the story hiding behind the numbers.
